Install

Runs on your own machine, so there's no queue, no upload, and no rate limit. Takes about a minute.

  1. 1

    Install the prerequisites

    Node, plus the two binaries that do the fetching and encoding.

    brew install node yt-dlp ffmpeg
  2. 2

    Clone and run

    git clone https://github.com/bohanl1u/SoundSnatcher.git cd SoundSnatcher npm install npm start
  3. 3

    Open it

    The tool runs at localhost:4747. That's the whole thing.

    open http://localhost:4747

Not on a Mac? Any system with Node 20+, yt-dlp and ffmpeg on the PATH will run it. npm run doctor checks that they're found.

How accurate is the analysis?

Measured against 17 reference tracks whose BPM and key are stated by the producers who made them. Real numbers, including the ones that aren't flattering.

14/17 BPM exact 3 octave-off (half/double time), 0 otherwise wrong
8/14 Key exact 1 fifth-error; relative major/minor is genuinely ambiguous

Tempo is reliable. Key is a hint, not a verdict. Detecting key from a finished master is hard — relative major and minor share six of seven notes, and a loop with no third in it has no mode to detect at all. Half and double-time readings are usually a genre convention rather than a mistake: drill is written at 140 and felt at 70, and both answers are defensible. If the key matters, check it by ear.

Questions

How do I get the BPM and key into the filename?

Tick Analyze key & BPM before hitting Snatch. The download then arrives as Track Name - 128BPM - Fmin.mp3. The interface previews the exact filename before you download it, so nothing is a surprise.

Why does this run locally instead of as a website?

Two reasons, both practical. YouTube heavily rate-limits datacenter IP addresses, so a cloud-hosted version fails constantly while a local one just works on your normal home connection. Running locally is also faster — there's no upload, no queue, and no limit on how long a video can be.

What formats can I get?

MP3 at 128, 192, 256 or 320 kbps, or 16-bit 44.1 kHz WAV. The source audio is downloaded once and re-encoded locally, so switching format doesn't re-download anything.

What is the Camelot code for?

Camelot notation turns keys into numbers on a wheel so that harmonically compatible tracks sit next to each other. A track in 5A mixes cleanly with 4A, 6A and 5B. Every key detection reports its Camelot code alongside the key name.

Does it collect any data about me?

No. It runs on your machine, has no accounts, no tracking, and no telemetry. The links you paste never leave your computer except to fetch the audio itself.

Is it free?

Yes, and open source under the MIT licence. There's no paid tier and nothing to sign up for.

What am I allowed to download with it?

Only audio you have the rights to use. SoundSnatcher is a tool, and what you point it at is your responsibility — respect copyright and the terms of the platform you're pulling from. It isn't affiliated with YouTube or Google.
