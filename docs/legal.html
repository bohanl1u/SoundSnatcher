What the software is

SoundSnatcher is a general-purpose tool that runs on your own computer. It downloads audio from a link you supply, converts it to MP3 or WAV, and can estimate a track's tempo and musical key. It is provided free of charge under the MIT licence.

Privacy

The tool has no accounts, no sign-in, and no tracking or analytics built into it. When you run it on your own machine, links you paste stay on that machine apart from the request needed to fetch the audio itself, and downloaded files are written only to your own computer.

If you use the public demo, the server keeps ordinary technical logs — such as IP address, timestamp and requested path — for security and abuse prevention, and retains them only as long as needed for that purpose. Submitted links are not stored in a database, and no profile of any user is built or shared. This static site sets no cookies.
